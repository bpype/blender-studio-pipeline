# Import Shot Render into Edit
Renders approved in `Render Review` or generated with `Publish Render` can be imported into your Edit using the `Pull` operator, which also imports published Shot renders.

1. Open your Edit .blend file by navigating to `Expo > Open Edit`.

<div style="padding: 12px; background: var(--color-bg-secondary, transparent); border-radius: 8px; margin-bottom: 20px;">
    <img src="/media/addons/expo_manager/topmenu_open_edit.jpg" width="600" alt="Invoke Open Edit" style="display: block; margin: auto;" />
</div>

2. Select the metadata strip or linked content strip for the Shot that has an approved render.
3. Use the `Pull` operator with `Import Latest Render` enabled. Select the Task Type, an empty channel, and the image file type to load the render into your Edit.
