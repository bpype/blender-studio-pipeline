# Import Shot Publish into Edit
Returning to your edit .blend file, you can now load the publish from the shot file into the edit.

1. Open your edit .blend file by navigating to `Expo > Open Edit`.
<div style="padding: 12px; background: var(--color-bg-secondary, transparent); border-radius: 8px; margin-bottom: 20px;">
    <img src="/media/addons/expo_manager/topmenu_open_edit.jpg" width="600" alt="Invoke Open Edit" style="display: block; margin: auto;" />
</div>

2. Select the Metadata Strip associated with your shot.
3. From the Sequencer Side Panel, select `Pull 1 Shot`.
<div style="padding: 12px; background: var(--color-bg-secondary, transparent); border-radius: 8px; margin-bottom: 20px;">
    <img src="/media/addons/expo_manager/edit_pull_shot_publish.jpg" width="600" alt="Import Shot Publish" style="display: block; margin: auto;" />
</div>

4. Enable `Import Latest Previews`, then select the Task Type you would like to load the publish from and an empty preview channel.
5. Your new publish will be imported with the same timing as the corresponding metadata strip.
