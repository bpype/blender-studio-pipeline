# Render Review

Once your shots have been rendered by Flamenco, use Expo's Render Review to compare render versions and select the version you would like to approve.

<div style="padding: 12px; background: var(--color-bg-secondary, transparent); border-radius: 8px; margin-bottom: 20px;">
    <img src="/media/addons/expo_manager/render_review_approve.jpg" width="600" alt="Render Review" style="display: block; margin: auto;" />
</div>


1. Go to `File > New > Render Review`.
2. In the dialog box, select the sequence name you would like to review.
3. Select the media strip for the render you are reviewing.
4. Select `Approve & Publish Render`:
	- Will take the MP4 of your Flamenco render and add it to the `publish_dir` set in your [expo configuration](/addons/expo-manager/configuration.md).
	- Will copy the image sequence of your Flamenco render to the `publish_frames` set in your [expo configuration](/addons/expo-manager/configuration.md).
