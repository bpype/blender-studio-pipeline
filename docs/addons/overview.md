### Installation

Some add-ons are already available on the [Extensions Platform](https://extensions.blender.org/team/blender-studio/), and others will arrive over time. You can search for available add-ons in Blender under "Get Extensions" in the user preferences.

To install add-ons that are not yet available there, follow these steps:
1. Download and unzip this repository from [this link](https://projects.blender.org/studio/blender-studio-tools/archive/main.zip).
2. In Blender, navigate to Preferences > File Paths > Script Directories.
3. Add an entry and browse to the `scripts-blender` folder (not the `addons` folder).
4. You can now enable any of our add-ons.


**You can report issues [here](https://projects.blender.org/studio/blender-studio-tools/issues).**
