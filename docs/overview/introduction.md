# Introduction

Blender Studio has been creating short films (open movies) and other open content for over 15 years, using Blender as the primary tool. An important goal of the open movies is to test and validate the functionality of Blender in the hands of a small team.

Over the years –while contributing to Blender's design and development– the studio has developed a set of extensions and tools _around_ Blender, which enable a more efficient collaboration. This documentation features different topics: Tools, Pipeline, and Studio Setup.
